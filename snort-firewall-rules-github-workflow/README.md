# Snort and Firewall Rules Lab

## Overview
This lab explores Intrusion Detection System (IDS) alert monitoring, packet capture, and firewall rule configuration using Snort, tcpdump, iptables, and Mininet in a CyberOps Workstation environment.

## Objectives
- Prepare the CyberOps virtual environment.
- Monitor Snort IDS alerts in real time.
- Identify suspicious network traffic.
- Capture network traffic using tcpdump.
- Configure iptables rules to block traffic to a specified server.
- Verify the firewall rule by testing the connection again.
- Terminate Mininet and clean up its processes.

## Tools and Technologies
- Cisco CyberOps Workstation
- Oracle VirtualBox
- Mininet
- Snort IDS
- iptables
- tcpdump
- Linux command-line tools

## Lab Activities
1. Prepared the virtual environment and checked network connectivity.
2. Started the Mininet topology and Snort.
3. Monitored IDS alerts during a simulated file download.
4. Captured network traffic to a PCAP file for investigation.
5. Added an iptables rule to block traffic to the target server.
6. Retested the connection to verify the blocking behavior.
7. Terminated Mininet and cleaned up the environment.
